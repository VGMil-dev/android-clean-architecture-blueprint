## <LucideIcon name="Target" size={24} color="var(--sl-color-accent)" /> Main Quests

No buscamos un código perfecto, buscamos código que **corra y sea profesional**. Estas son tus misiones principales:

<Steps>
1.  **El Momento "Scanner"**
    Tu App tiene que levantar la cámara y, en cuanto detecte un QR válido, mandarte directo a la pantalla de pago.
    :::tip[Bonus Point]
    Sumale un sonido o una vibración (`Haptics`) cuando el escaneo sea exitoso. <Badge text="+5 pts" variant="success" />
    :::

2.  **Lógica del Checkout**
    Queremos ver el flujo real (aunque sea mock):
    *   Pantalla de resumen con el detalle de lo que vas a pagar.
    *   Un botón de "Pagar Ahora" que dispare el servicio.
    *   Manejo de estados: Mientras carga ⮕ Éxito o Error.

3.  **Clean Code (Feature-Based)**
    Nada de meter todo en un solo archivo. Vamos a respetar la estructura modular que vinimos trabajando. Así es como debería quedar tu árbol de archivos:
</Steps>

```bash
📂 src/
├── 📱 app/                      # Pantallas y Navegación
│   ├── (auth)/                  # Login / Register
│   ├── (tabs)/                  # Feed / Perfil
│   └── (checkout)/              # 💳 El flujo de pagos
│       ├── _layout.tsx
│       ├── scanner.tsx          # Pantalla de la cámara
│       └── payment.tsx          # Pantalla de confirmación
├── 🧠 lib/                      # La lógica pesada
│   ├── core/
│   │   ├── payments/            # Adaptadores de pago (Mock)
│   │   └── qr/                  # Utilidades de escaneo
│   └── modules/                 # Hooks de negocio
│       └── useCheckout.ts
└── 🧱 components/               # Tus átomos de UI
```
