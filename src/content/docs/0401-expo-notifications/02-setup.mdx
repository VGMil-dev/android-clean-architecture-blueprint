Antes de escribir una sola línea de código complejo, necesitamos preparar nuestro arsenal. Vamos a instalar las librerías oficiales que nos permitirán comunicarnos con el sistema operativo y nuestro backend.

## 1. Instalación de Dependencias

```bash
npx expo install expo-notifications expo-device expo-constants
npx expo install @supabase/supabase-js @react-native-async-storage/async-storage
```

### ¿Por qué estas librerías?

<CardGrid stagger>
    <Card title="expo-notifications" icon="seti:lock">
        El núcleo. Maneja la recepción de notificaciones, permisos y listeners.
    </Card>
    <Card title="expo-device" icon="laptop">
        Crítico para identificar si estamos en un dispositivo físico.
    </Card>
    <Card title="supabase-js" icon="rocket">
        Cliente de DB y Auth.
    </Card>
    <Card title="AsyncStorage" icon="document">
        Persistencia local segura para Móvil. ⚠️ ¡Cuidado en Web!
    </Card>
</CardGrid>

:::note[Importante: Soporte Web]
`AsyncStorage` es el estándar para React Native (Mobile), pero en la web puede no ser la opción por defecto deseada o más optimizada.

Para una arquitectura robusta, aislaremos el almacenamiento en un módulo <Highlight variant="primary">core/storage</Highlight>. Esto nos permite usar una "flag" o detección de plataforma para alternar entre:

- 📱 Mobile -> @react-native-async-storage/<Highlight variant="purple">async-storage</Highlight>
- 🌐 Web -> <Highlight variant="green">localStorage</Highlight> (nativo del navegador)

Veremos la implementación de este adaptador en el siguiente módulo.
:::

## 2. Configuración de `app.json`

Asegúrate de que tu `app.json` tenga configurado el plugin de notificaciones si necesitas personalizar iconos o colores (opcional por ahora, pero recomendado para producción).

```json {7-9}
{
  "expo": {
    "plugins": [
      [
        "expo-notifications",
        {
          "icon": "./assets/notification-icon.png",
          "color": "#bd93f9",
          "sounds": ["./assets/sounds/custom-sound.wav"]
        }
      ]
    ]
  }
}
```
