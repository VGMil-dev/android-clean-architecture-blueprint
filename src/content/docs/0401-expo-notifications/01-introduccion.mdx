:::tip[Objetivo]
Esta guía te llevará paso a paso en la construcción de un sistema robusto de notificaciones. No solo aprenderás a "hacer que funcione", sino a arquitecturarlo como un **Senior Engineer**.

Al final de este viaje, tendrás:
*   Aplicación móvil moderna con **Expo Router**.
*   Gestión de sesiones e identidad con **Supabase Auth**.
*   Base de datos PostgreSQL real con **Triggers** automatizados.
*   Experiencia de usuario premium con **Animaciones** y feedback visual.
:::
